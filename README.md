# 📝 Notes App

A simple Notes App built using **React**, **React Router**, **Axios**, and **JSON Server**. The application allows users to manage notes with full CRUD functionality along with search and pagination.

## Features

- Create a new note
- View note details
- Update existing notes
- Delete notes
- Search notes by title
- Pagination
- Responsive user interface

## Tech Stack

- React
- React Router DOM
- Axios
- JSON Server
- CSS

## Setup

1. Clone the repository
2. Install dependencies

```bash
npm install
```

3. Start JSON Server

```bash
npm run server
```

4. Start React application

```bash
npm run dev
```
